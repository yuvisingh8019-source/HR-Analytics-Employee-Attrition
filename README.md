# HR Analytics Dashboard using Power BI

📌 Project Overview
This project focuses on analyzing employee data and creating an interactive HR Analytics Dashboard using Microsoft Power BI. The dashboard helps understand employee distribution, attrition patterns, and workforce trends through interactive visualizations and key performance indicators (KPIs).

🎯 Project Objectives
> Analyze overall employee data.
> Understand employee attrition patterns.
> Explore employee distribution across departments and age groups.
> Analyze workforce demographics.
> Present HR metrics through an interactive dashboard.

🛠️ Tools & Technologies
> Microsoft Power BI – Dashboard development and visualization
> Power Query – Data cleaning and transformation
> DAX – Calculated measures and KPI calculations
> Excel – Data source and preparation


📊 Dashboard Features
> Total Employees
> Employee Attrition Analysis
> Department-wise Employee Distribution
> Age Group Analysis
> Gender Distribution
> Interactive Slicers for filtering employee data
> KPI Cards for summarizing important metrics

🔍 Key Insights
The dashboard allows users to explore:
> Employee distribution across different departments.
> Workforce composition by gender and age group.
> Employee attrition patterns.
> Differences in workforce metrics when applying interactive filters.

🚀 How to Use This Project
1. Download the .pbix file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded file in Power BI Desktop.
4. Explore the charts and use the slicers to analyze employee data.

📚 Learning Outcomes
> Data cleaning and transformation using Power Query.
> Creating DAX measures and KPI cards.
> Designing interactive Power BI dashboards.
> Analyzing employee data using visualizations.
> Presenting business information through data analytics.
